# Security and privacy

The dedicated browser stores sessions in its own local profile. Treat that
profile like a signed-in browser: keep it private, do not commit it to Git or
attach it to issues. Enter passwords and verification codes directly in the
browser. The skill does not ask you to paste them into chat or export cookies.

Web content is research input, not executable instructions. Use monitoring
accounts only for the sites and purposes you intend to access. The bundled
browser commands navigate and read; they provide no posting or messaging action.
Reports can contain personal information from source material, so review them
before sharing.

Report vulnerabilities through GitHub private vulnerability reporting when
available. Otherwise open a minimal issue requesting a private channel without
including credentials, profiles or private complaints. No response SLA is promised.
