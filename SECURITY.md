# Security and privacy

This project processes local records and instructs an authorized agent. It does not require secrets or execute remote page instructions. Limit files to trusted local inputs and keep reports private until reviewed; source URLs and narrative text can contain personal information.

Do not put live credentials, private complaints or exploit details into a public issue. Use GitHub's private vulnerability reporting if it is enabled for this repository; otherwise open a minimal issue requesting a private reporting channel without including sensitive details. No response SLA is promised.

The report renderer should escape active HTML and Markdown structure from observations. Validation is structural, not source authentication. Do not use the toolkit as an identity verifier, automated legal judgment or permission to interact with accounts.
